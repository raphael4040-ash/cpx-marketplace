# CPX 기록판 연결

웹 기록판에서 발급받은 연결 코드를 이 컴퓨터에 저장해, 평가가 끝날 때마다 결과가
사용자 계정에 자동으로 쌓이도록 만듭니다.

연결 코드: `$ARGUMENTS`

## 수행 절차

1. **코드가 비어 있으면** 아래를 안내하고 중단한다.

   > 연결 코드가 필요합니다. 기록판 웹앱에 로그인 → **이용 방법** 탭 → **연결 코드 만들기** →
   > 복사한 코드를 `/cpx:pair <코드>` 형태로 붙여넣어 주세요.

2. **코드 형식을 확인한다.** 공백 없는 base64url 문자열(영문·숫자·`-`·`_`) 이어야 하고
   보통 수백 자 이상이다. 명백히 형식이 아니면 다시 복사해 달라고 안내하고 중단한다.

3. **토큰 파일을 만든다.** 사용자 홈 디렉터리의 `.cpx/token` 에 연결 코드만 한 줄로 저장한다.
   (Windows는 `%USERPROFILE%\.cpx\token`, macOS/Linux는 `~/.cpx/token`)
   디렉터리가 없으면 만든다. 파일에는 코드 외에 아무것도 쓰지 않는다.

4. **파일 권한을 좁힌다.** 토큰은 계정 자체이므로 본인만 읽게 만든다.

   - macOS/Linux: `chmod 600 ~/.cpx/token`
   - Windows: 홈 디렉터리 ACL 을 물려받아 보통 본인·SYSTEM·Administrators 만 읽을 수
     있지만, 상속된 그룹이 더 붙어 있을 수 있다. 상속을 끊고 본인만 남긴다:

     ```
     icacls "%USERPROFILE%\.cpx\token" /inheritance:r /grant:r "%USERNAME%:(R,W)"
     ```

5. **연결 결과를 알린다.**

   > ✅ 연결됐습니다. 이제 `/cpx:start` 로 연습하고 `평가` 까지 마치면 결과가 자동으로 기록판에 올라갑니다.

6. **주의사항을 한 번 짚어준다.**

   > 이 코드는 비밀번호와 같은 힘을 가집니다. `~/.cpx/token` 을 다른 사람과 공유하거나
   > 저장소에 커밋하지 마세요. 유출된 것 같으면 기록판 **설정 → 완전 무효화**로
   > 비밀번호까지 바꾸세요. **연결 코드 무효화**만 하면 업로드 경로만 막힐 뿐,
   > 코드에 담긴 로그인 자격은 그대로 살아 있습니다.

## 전사 저장 끄기

사용자가 "문진 내용은 올리지 마" 라고 하면 `~/.cpx/config` 파일에 아래 한 줄을 쓴다.

```
transcript=0
```

이렇게 하면 대화 내용이 **아예 전송되지 않고** 점수와 총평만 업로드된다.
다시 켜려면 그 파일을 지우거나 `transcript=1` 로 바꾸면 된다.
(웹앱 **설정** 탭의 동의 스위치는 서버 쪽 2차 방어선이며, 이 파일은 전송 자체를 막는다.)

## 업로드 주소 바꾸기 (자체 배포한 경우만)

워커를 직접 배포해 쓰는 사람은 `~/.cpx/config` 에 주소를 적는다.

```
endpoint=https://내-워커-주소/upload
```

`https://` 로 시작하지 않으면 무시되고 기본 주소로 간다.
예전에 쓰던 `CPX_ENDPOINT` 환경변수는 더 이상 읽지 않는다 — 프로젝트 설정만
건드려도 심을 수 있어서, 그것만으로 토큰과 전사가 남의 서버로 갈 수 있었다.

## 연결 해제

사용자가 연결을 끊고 싶다고 하면 `~/.cpx/token` 파일을 삭제한다.
그 즉시 이 컴퓨터에서의 업로드가 멈춘다. 코드 자체를 죽이려면 기록판 **설정 → 완전 무효화**를
안내한다 — 비밀번호를 바꾸면 Firebase 가 그 계정의 로그인 자격을 서버에서 전부 폐기한다.
**연결 코드 무효화**는 업로드 경로만 막을 뿐이라 유출 상황에서는 부족하다.
