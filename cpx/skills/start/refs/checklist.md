# CPX 채점표 (실기시험 스타일, 100점 배점)

`평가` 시 이 배점표를 기준으로 항목별 O/△/X와 배점을 매기고, 마지막에 총점·등급·총평을 낸다.
실제 국시원 공식 채점표를 그대로 재현한 것은 아니며, 그 형식(항목별 배점 + PPI 별도 평가)을
본떠 재구성한 연습용 기준이다. `진찰` 신호 없이 `평가`가 들어오면 신체진찰 항목은
"미실시(0점)"으로 처리하고 총평에 그 사실을 명시한다.
예외: "나쁜 소식 전하기" 케이스는 애초에 신체진찰 항목이 없으므로 II. 20점은 항상 만점 처리한다.
"기본진료술기" 케이스는 이 배점표 대신 `topics.md`의 필수 임상술기 수행 순서·정확성 기준으로 별도 채점한다.

배점: O(만점) / △(부분 인정, 절반) / X(0점)

---

## I. 병력청취 (History taking) — 60점

### 1. 도입 (5점)
- [ ] 자기소개 및 신분 확인 (2점)
- [ ] 환자 확인 — 이름/나이 (1점)
- [ ] 개방형 질문으로 방문 목적 시작 (2점)

### 2. 주호소 & 현병력 (20점)
- [ ] 주호소 명확화 (2점)
- [ ] 발병시기 Onset (2점)
- [ ] 경과/양상 Character (2점)
- [ ] 위치 및 방사 여부 (2점, 해당 없으면 만점 처리)
- [ ] 악화/완화 요인 (3점)
- [ ] 강도 Severity 0~10 (2점)
- [ ] 동반 증상 확인 (4점)
- [ ] 과거 유사 증상 여부 (3점)

### 3. ICE Framework (6점)
- [ ] Ideas — 환자가 생각하는 원인 (2점)
- [ ] Concerns — 가장 걱정되는 부분 (2점)
- [ ] Expectations — 방문에서 기대하는 것 (2점)

### 4. Red Flag / 감별진단 문진 (10점)
- [ ] 케이스별 필수 위험 증상 질문 (topics.md 기준) (6점)
- [ ] 전신 증상 확인 — 체중감소/발열/야간발한 (4점)

### 5. 과거력·약물력·가족력·사회력 (12점)
- [ ] 과거 병력 및 수술력 (3점)
- [ ] 복용 약물 및 알레르기 (3점)
- [ ] 가족력 (2점)
- [ ] 사회력 — 흡연/음주/직업 (3점)
- [ ] 해당 시 산과력/월경력 (1점, 해당 없으면 만점 처리)

### 6. Safety Netting (7점)
- [ ] 악화 시 대처 방법 안내 (3점)
- [ ] 재방문 기준 안내 (2점)
- [ ] 추가 검사/다음 단계 안내 (2점)

---

## II. 신체진찰 (Physical exam) — 20점

`진찰` 신호 이후에만 채점한다. topics.md의 "PE 초점"을 기준으로 판단한다.

- [ ] 진찰 전 설명 및 동의 (3점)
- [ ] 활력징후 확인 (혈압/맥박/호흡수/체온 등 케이스에 맞게) (5점)
- [ ] 케이스 핵심 진찰 수기 1 — topics.md PE 초점 참고 (6점)
- [ ] 케이스 핵심 진찰 수기 2 — topics.md PE 초점 참고 (6점)

(케이스에 따라 핵심 수기가 1개뿐이면 12점을 해당 항목에 몰아 배점)

---

## III. 환자-의사 관계 PPI (Patient-Physician Interaction) — 20점

- [ ] 라포 형성 — 인사, 편안한 분위기 (4점)
- [ ] 질문 순서 — 개방형→폐쇄형, 한 번에 한 가지씩 (4점)
- [ ] 경청 및 공감 표현 (4점)
- [ ] 요약 및 확인 Summarize & check back (4점)
- [ ] 언어 사용 — 전문용어 지양, 이해하기 쉬운 설명 (2점)
- [ ] 마무리 인사 및 추가 질문 확인 (2점)

---

## 총점 및 등급

| 총점 | 등급 |
|---|---|
| 90~100 | 우수 |
| 80~89 | 양호 |
| 70~79 | 보통 (개선 필요) |
| 70 미만 | 미흡 |

## 종합 평가 출력 형식
1. I/II/III 각 섹션별 항목-배점표 (O/△/X + 배점 + 짧은 코멘트)
2. 섹션별 소계 (예: 병력청취 52/60, 신체진찰 14/20, PPI 17/20)
3. 총점 및 등급
4. 잘한 점 2~3가지
5. 개선이 필요한 점 2~3가지 (구체적 질문 예시 포함)
6. 총평 한 줄
