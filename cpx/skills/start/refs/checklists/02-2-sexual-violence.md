# 주호소별 채점표 — 성폭력

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 환자의 통제감 확보 → 사건 확인 → 응급 위험(임신·성병) → 지원과 법적 절차 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 면담과 사건 확인 (10점)
- [ ] 안전·비밀보장 설명, 환자가 원하는 속도로 진행하기 (2)
- [ ] 사건 시각·장소 — 72시간 이내인지 (2)
- [ ] 가해자가 누구인지(아는 사람인지)·인원 (1)
- [ ] 폭력 방식·삽입 여부(질·구강·항문)를 개방적으로, 세세히 캐묻지 않기 (3)
- [ ] 저항 중 폭력·음주·약물 사용 여부(약물 관련 의심) (2)

### B. 응급 위험 (10점)
- [ ] 현재 신체 손상·출혈·통증 (2)
- [ ] 사건 뒤 씻음·옷 갈아입음·배뇨 여부(증거 보존) (2)
- [ ] 임신 가능성 — 마지막 월경일·피임 (2)
- [ ] 성병·HIV 노출 가능성, 콘돔 사용 여부 (2)
- [ ] 자살·자해 생각과 심리 상태 (2)

### C. 지원과 배경 (10점)
- [ ] 경찰 신고 의사와 법적 절차 안내 (2)
- [ ] 안전한 귀가·동행할 사람 (2)
- [ ] 가족·지인의 지지 (1)
- [ ] 기저질환·복용 약·알레르기(응급피임·예방 약 처방 대비) (2)
- [ ] 과거 성폭력 경험·정신과 병력 (1)
- [ ] 환자가 원하는 것 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 진찰 전 상세 설명·동의, 언제든 중단할 수 있음을 알림 (3)
- [ ] 전신 손상 시진 — 멍·긁힌 상처·물린 자국 (3)
- [ ] 성폭력 응급키트로 증거물 채집 — 순서·포장·라벨·보관 연속성 (4)
- [ ] 질 분비물 검체 채취(감염 검사) (2)

증거물 채집은 환자 동의 아래 진행하며, 진찰 도중 환자가 멈추길 원하면 즉시 멈추는지도 본다.

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 임신 검사, 성병·HIV·B형간염 검사.
  있으면 더 좋음(없어도 O) — 추적 검사 시점.
  진단과 어긋나면 X.
- [ ] 정서 지원과 상담·치료 연결 — 환자 잘못이 아님을 분명히 전달 (1)
- [ ] 응급피임·성병 예방·HIV 노출 후 예방 안내, 해바라기센터·1366 연결, 재방문 시점 (2)
