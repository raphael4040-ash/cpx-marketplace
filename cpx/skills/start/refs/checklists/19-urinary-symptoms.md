# 주호소별 채점표 — 배뇨 이상

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 배뇨 증상 → 상부요로 감염·신경계·생식기 동반 증상 → 원인 병력 → 비뇨생식기·신경 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 배뇨 증상 (10점)
- [ ] 빈뇨·야간뇨·절박뇨 (2)
- [ ] 배뇨통·소변 줄기 약함·망설임 (2)
- [ ] 소변 찔끔 — 기침 시인지, 급하게 못 참는지 (2)
- [ ] 발병 시기와 경과 (1)
- [ ] 소변량·색·혈뇨·거품 (2)
- [ ] 반복 여부(반복 감염) (1)

### B. 동반 증상 (10점)
- [ ] 옆구리 통증·열·오한(상부요로 감염) (3)
- [ ] 하복부 통증 (1)
- [ ] 질·요도 분비물, 성 접촉력 (2)
- [ ] 체중감소·혈뇨(종양) (1)
- [ ] 다리 힘 빠짐·감각 저하·변 조절 문제(신경계) (2)
- [ ] 임신 가능성 (1)

### C. 원인 병력 (10점)
- [ ] 당뇨병·고혈압·신장 질환 (2)
- [ ] 요로결석·감염·수술·분만력 (2)
- [ ] 전립샘 병력(남성)·폐경(여성) (2)
- [ ] 복용 약 — 이뇨제·항콜린제 (2)
- [ ] 카페인·음주·수분 섭취 (1)
- [ ] 요로 기형·소아기 감염 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 활력징후·체온 (1)
- [ ] 하복부 촉진 — 방광 팽만 (2)
- [ ] 늑골척추각 타진 (2)
- [ ] 외부 생식기 진찰(남성은 음낭·요도구·전립샘 직장 진찰, 여성은 외음부·골반) (3)
- [ ] 신경학적 검사 — 하지 근력·감각·항문 반사 (2)
- [ ] 소변 시험지 검사 언급 (2)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  소변검사·소변배양, 혈액검사, 복부 초음파, 전립샘 특이항원, 방광경, 요역동학검사. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 수분 섭취, 배뇨 습관, 항생제 필요성 (1)
- [ ] 재방문·응급 기준 — 열·옆구리 통증, 소변이 아예 안 나옴, 혈뇨 지속 (2)
