# 주호소별 채점표 — 소화불량

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 증상 특성 → 경고 증상(기질적 원인) → 위험요인·약물 → 복부 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 소화불량 자체 (10점)
- [ ] 발병 시기와 기간 (2)
- [ ] 위치와 양상 — 상복부 통증·팽만·조기 포만 (2)
- [ ] 식사와의 관계 — 식후·공복·야간 (2)
- [ ] 악화·완화 요인 — 제산제 (2)
- [ ] 이전 유사 증상·반복 (2)

### B. 경고 증상 (10점)
- [ ] 체중감소 (2)
- [ ] 토혈·검은 변 (2)
- [ ] 삼킴 곤란·삼킬 때 통증 (2)
- [ ] 반복 구토 (1)
- [ ] 빈혈 증상 — 어지러움·창백 (1)
- [ ] 황달·복부 덩이 (1)
- [ ] 50세 이후 새로 시작 (1)

### C. 원인과 위험요인 (10점)
- [ ] 헬리코박터·궤양 병력, 위암 가족력 (2)
- [ ] 소염진통제·스테로이드·아스피린·철분 (2)
- [ ] 음주·흡연·커피·자극적 식사 (2)
- [ ] 스트레스·우울·수면 (1)
- [ ] 속쓰림·신물·기침(역류) (1)
- [ ] 간·담도·췌장 병력(담석·췌장염) (1)
- [ ] 복부 수술 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 복부 진찰 — 시진 → 청진 → 타진 → 촉진 순서 (5)
- [ ] 상복부 압통 위치와 반발통 (1)
- [ ] 간·비장·담낭 촉진, Murphy 징후 (2)
- [ ] 복부 덩이·복수·림프절(Virchow) (2)
- [ ] 결막 창백·황달 (1)
- [ ] 직장 진찰(흑색변 확인) (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  경고 증상이 없으면 헬리코박터 검사·경험적 치료도 정답이다. 경고 증상이 있으면 위내시경, 혈액검사(빈혈·간기능·췌장 효소), 복부 초음파. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 식사 습관·금연·절주, 약 복용, 헬리코박터 제균 (1)
- [ ] 재방문·응급 기준 — 토혈·검은 변, 체중감소, 삼킴 곤란, 심한 복통 (2)
