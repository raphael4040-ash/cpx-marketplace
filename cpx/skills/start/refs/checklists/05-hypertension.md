# 주호소별 채점표 — 고혈압

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 고혈압 병력과 측정 → 이차 고혈압·합병증 → 위험인자와 약물 → 혈압 측정 술기 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 고혈압 병력 (10점)
- [ ] 처음 알게 된 시기·수치·측정 장소(가정·병원) (3)
- [ ] 증상 — 두통·어지러움·가슴 답답 (2)
- [ ] 이전 치료·약 복용과 순응도 (2)
- [ ] 가정혈압 측정 여부 (1)
- [ ] 최근 혈압 변화와 계기 (2)

### B. 이차 고혈압과 합병증 (10점)
- [ ] 신장 — 거품뇨·부종·혈뇨·야간뇨 (2)
- [ ] 내분비 — 발작성 두통·두근거림·땀, 근력 약화·다뇨, 체중·얼굴 변화 (3)
- [ ] 코골이·낮 졸림(수면무호흡) (1)
- [ ] 시야 이상·흉통·숨참·마비(장기 합병증) (3)
- [ ] 임신 여부·경구피임약 (1)

### C. 위험인자와 원인 (10점)
- [ ] 고혈압·뇌졸중·심근경색 가족력 (2)
- [ ] 흡연·음주·짠 음식·카페인 (2)
- [ ] 운동·체중·식습관 (2)
- [ ] 혈압을 올리는 약 — 소염진통제·감기약·스테로이드·피임약·한약(감초) (2)
- [ ] 당뇨병·이상지질혈증·신장 질환 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 혈압 측정 술기 — 5분 안정, 앉은 자세, 팔 심장 높이, 맞는 커프, 양팔 측정 (5)
- [ ] 맥박·심장 청진 (2)
- [ ] 복부 혈관 잡음 청진·옆구리 타진(신장) (2)
- [ ] 안저검사·경정맥·하지 부종(합병증) (1)
- [ ] 체질량·복부 비만·달덩이 얼굴·갑상샘 확인 (2)

혈압 측정 술기는 필수 임상술기이므로 순서·자세·커프 크기 중 빠진 것이 있으면 그만큼 △ 로 깎는다.

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  소변검사·크레아티닌·전해질·혈당·지질검사, 심전도, 필요 시 24시간 활동혈압. 진단과 어긋나면 X.
- [ ] 생활 교육 — 염분·체중·금연·절주·운동, 약 복용 지속의 중요성 (1)
- [ ] 재방문·응급 기준 — 혈압 180/120 이상, 심한 두통·시야 이상·흉통·마비·숨참 (2)
