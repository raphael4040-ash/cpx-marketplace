# 주호소별 채점표 — 두근거림

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~D | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 E | 12 |
| I-6 Safety netting (7) | 아래 F | 7 |

면담은 두근거림의 양상(시작·끝·규칙성) → 심장·갑상샘·불안 동반 증상 → 원인 병력과 약물·기호품 →
응급 신호 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의 "질문 순서"에
반영한다.

## 병력청취

### A. 두근거림 자체 (10점)
- [ ] 발병 시기와 지속 시간 — 몇 초·몇 분·몇 시간 (2)
- [ ] 시작과 끝 양상 — 갑자기 시작해 갑자기 멈추는지, 서서히인지 (2)
- [ ] 규칙성과 속도 — 맥박을 짚어 보았는지, 규칙적인지 불규칙한지, 분당 횟수 (2)
- [ ] 유발·완화 요인 — 운동, 커피, 스트레스, 숨 참기·기침으로 멈추는지, 누울 때 (2)
- [ ] 빈도와 이전 발작 (2)

### B. 동반 증상 (8점)
- [ ] 흉통 (2)
- [ ] 호흡곤란 (1)
- [ ] 어지러움·실신 (2)
- [ ] 식은땀 (1)
- [ ] 손떨림·더위 못 참음·체중감소·설사 — 갑상샘 감별 (1)
- [ ] 불안·죽을 것 같은 느낌·손발 저림 (1)

### C. 원인 병력 (8점)
- [ ] 심장질환(부정맥·판막·심근경색)·고혈압 (2)
- [ ] 갑상샘질환·빈혈·당뇨병 (1)
- [ ] 복용 약 — 감기약, 갑상샘약, 이뇨제, 천식 흡입제, 다이어트약 (2)
- [ ] 카페인·에너지음료·음주·흡연·약물 (2)
- [ ] 급사·심장병 가족력 (1)

### D. 응급 신호와 정서 요인 (4점)
- [ ] 안정 시 지속·반복 실신·가슴 답답함 등 응급 신호 (2)
- [ ] 스트레스·수면·불안 이력 (2)

## 신체진찰

### E. 핵심 진찰 (12점)
- [ ] 맥박 촉진 — 분당 횟수와 규칙성, 충분한 시간 동안 (3)
- [ ] 심장 청진 — 심음, 잡음, 부정맥 (3)
- [ ] 혈압 측정 (2)
- [ ] 갑상샘 시진·촉진, 손떨림·안구 돌출·피부 (2)
- [ ] 폐 청진·경정맥 확장·하지 부종 (1)
- [ ] 결막 창백 확인 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### F. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  모든 경우 12유도 심전도, 발작성이면 24시간 심전도·이벤트 기록, 갑상샘 기능검사, 혈색소·전해질,
  구조 이상 의심에 심초음파. 심전도 없이 약만 처방하는 식으로 진단과 어긋나면 X.
- [ ] 치료와 생활 교육 — 카페인·음주 줄이기, 유발 요인 피하기, 발작 때 맥박 세어 기록 (1)
- [ ] 재방문·응급 기준 — 흉통, 실신, 심한 숨참, 안정 시 지속되는 두근거림 (2)
