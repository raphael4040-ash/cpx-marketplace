# 주호소별 채점표 — 쉽게 멍이 듦

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 멍의 양상 → 출혈 성향과 전신 증상 → 약물·원인 → 피부와 출혈 관련 장기 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 멍 (10점)
- [ ] 발생 시기와 경과 — 최근 시작인지 오래전부터인지 (2)
- [ ] 부위·크기·개수 (2)
- [ ] 외상 없이 생기는지, 가벼운 충격으로 생기는지 (2)
- [ ] 통증·솟아오름(자반과 혈종 구별) (1)
- [ ] 멍이 낫는 기간·지혈 시간 (1)
- [ ] 이전 시술 후 출혈(발치·수술) (2)

### B. 출혈 성향과 전신 증상 (10점)
- [ ] 코피·잇몸 출혈 (2)
- [ ] 월경과다·혈변·혈뇨 (2)
- [ ] 관절·근육 출혈(혈우병) (2)
- [ ] 열·체중감소·뼈 통증·밤에 땀(혈액암) (2)
- [ ] 피로·창백·잦은 감염 (1)
- [ ] 발진·관절통·복통·부종(혈관염) (1)

### C. 원인 (10점)
- [ ] 복용 약 — 아스피린·소염진통제·와파린·스테로이드·항생제·한약·건강기능식품 (3)
- [ ] 출혈질환 가족력 (2)
- [ ] 간·신장 질환·영양(비타민 C·K)·음주 (2)
- [ ] 최근 감염·백신 (1)
- [ ] 암·자가면역 병력 (1)
- [ ] 나이·노쇠 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 피부 관찰 — 멍의 위치·크기·색, 자반·점상출혈 구별 (4)
- [ ] 출혈 관련 장기 — 구강 점막·잇몸·결막·비강 (2)
- [ ] 림프절·간·비장 촉진 (3)
- [ ] 관절 부종·움직임 (1)
- [ ] 활력징후·창백 (1)
- [ ] 안전수혈술기 — 환자·혈액 2인 확인 (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  혈액검사(혈소판 수·응고검사 PT/aPTT·혈색소), 말초혈액 도말, 간기능, 필요 시 골수검사. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인 약 조정, 외상 피하기, 소염진통제 주의 (1)
- [ ] 재방문·응급 기준 — 지혈되지 않는 출혈, 혈변·토혈, 심한 두통, 열 (2)
