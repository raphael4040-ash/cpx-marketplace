# 주호소별 채점표 — 자살

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 현재 자살 사고 → 이번 시도와 위험도 → 원인·보호 요인 → 정신상태와 신체 상태 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 현재 자살 사고 (10점)
- [ ] 자살 생각을 직접 묻기 — 필수 (4)
- [ ] 생각의 빈도·강도·시작 시기 (2)
- [ ] 자살 계획·수단·시기 (3)
- [ ] 지금의 상태(안전한지) (1)

### B. 시도와 위험 (10점)
- [ ] 이번 시도 여부·방법, 과다 복용한 약의 종류와 양(신체 응급 판단) (3)
- [ ] 과거 시도·자해 (2)
- [ ] 가족 자살력 (1)
- [ ] 의도 — 죽음을 원하는지, 고통에서 벗어나고 싶은지 (1)
- [ ] 시도 뒤 감정(후회·안도)과 재시도 가능성 (3)

### C. 원인과 보호 요인 (10점)
- [ ] 우울증·정신과 병력 (2)
- [ ] 알코올·약물 문제 (2)
- [ ] 최근 상실·스트레스·관계·경제 문제 (2)
- [ ] 만성 통증·중병 (1)
- [ ] 보호 요인 — 가족·자녀·종교 (2)
- [ ] 지지체계 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 정신상태 평가 — 외모·기분·정동·사고·판단·병식 (4)
- [ ] 활력징후·의식·중독 징후 (3)
- [ ] 신체 손상 확인 — 자해 흔적 (2)
- [ ] 동공·호흡·피부(약물 중독 징후) (2)
- [ ] 산소포화도·혈당 확인 언급 (1)

자살 사고·계획을 직접 묻지 않았거나 판단하는 어투로 물었다면 A 의 해당 항목은 X 로 하고 개선점에 인용한다.

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  약물 과다 복용 시 혈액검사·약물 농도·심전도, 정신과 평가·위험 평가 척도. 진단과 어긋나면 X.
- [ ] 치료 방향 — 안전 확보, 위험이 높으면 입원·보호자 연계, 치료 접근성 제공 (1)
- [ ] 안전 계획과 응급 기준 — 자살 생각 악화 시 1393·119·응급실, 지지자 연락처, 위험 수단 제거 (2)
