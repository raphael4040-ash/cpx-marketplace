# 주호소별 채점표 — 불안

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 불안 양상(공황 포함) → 신체 증상과 감별 → 스트레스·배경과 위험 → 정신상태 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 불안 자체 (10점)
- [ ] 걱정의 내용과 대상 (2)
- [ ] 발병 시기와 지속 기간 (2)
- [ ] 공황발작 — 갑자기 시작해 수 분 안에 최고조인 극심한 공포 (2)
- [ ] 회피 행동·강박·외상 사건 (2)
- [ ] 일상 기능 저하 (2)

### B. 동반 증상과 감별 (10점)
- [ ] 신체 증상 — 두근거림·떨림·숨참·식은땀·저림 (2)
- [ ] 수면·집중력·근육 긴장 (2)
- [ ] 우울·자살 생각 (2)
- [ ] 갑상샘·심장·호흡기 등 신체질환 증상 (2)
- [ ] 음주·카페인·약·금단 (1)
- [ ] 정신과 병력·치료 경험 (1)

### C. 스트레스와 위험 (10점)
- [ ] 스트레스 요인 — 직장·가족·사건 (3)
- [ ] 외상 경험 (2)
- [ ] 가족력 (1)
- [ ] 카페인·흡연·음주·수면 (2)
- [ ] 사회적 지지 (1)
- [ ] 자살·자해 위험 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 정신상태 평가 — 외모·기분·정동·사고·판단·병식 (4)
- [ ] 활력징후 — 맥박·혈압·호흡 (2)
- [ ] 갑상샘 시진·촉진, 손떨림 (2)
- [ ] 심장·폐 청진 (2)
- [ ] 반사·근긴장 확인 (1)
- [ ] 물질 사용 징후 (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  갑상샘 기능·혈당·심전도(신체질환 감별), 불안 평가 설문. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 호흡 이완, 카페인 줄이기, 상담·약물치료 선택지 (1)
- [ ] 재방문·응급 기준 — 흉통·실신, 자살 생각, 일상 기능 악화 (2)
