# 주호소별 채점표 — 월경통

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 통증 특성 → 이차 월경통(자궁내막증) 동반 증상 → 원인 병력 → 복부·골반 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 통증 (10점)
- [ ] 통증 시기 — 월경 전·중·후, 시작 나이 (2)
- [ ] 위치·양상·강도 (2)
- [ ] 지속 시간·진통제 효과 (2)
- [ ] 시간에 따른 변화 — 점점 심해지는지 (2)
- [ ] 일상에 미치는 영향 — 결석·결근 (2)

### B. 동반 증상과 감별 (10점)
- [ ] 월경량·불규칙·월경 외 통증 (2)
- [ ] 성교통·배변통·배뇨통(자궁내막증) (3)
- [ ] 불임·임신 시도 (1)
- [ ] 질 분비물·열·골반염 (1)
- [ ] 구토·설사·두통 (1)
- [ ] 임신 가능성 (2)

### C. 원인 (10점)
- [ ] 자궁내막증·근종 가족력 (2)
- [ ] 산부인과 병력·수술·자궁 내 장치 (2)
- [ ] 복용 약·경구피임약 사용 (2)
- [ ] 스트레스·운동·흡연 (1)
- [ ] 초경 나이와 주기 (1)
- [ ] 자궁경부 도말 검사 이력 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 활력징후 (1)
- [ ] 복부 진찰 — 시진 → 청진 → 타진 → 촉진 (3)
- [ ] 골반 진찰 — 설명·동의·자세, 외음부, 질경, 질 분비물 검체, 양손 촉진(자궁 위치·부속기 압통·결절) (6)
- [ ] 자궁경부 도말 (1)
- [ ] 임신 검사 언급 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  일차 월경통이 의심되면 검사 없이 진통제 시험 치료도 정답이다. 이차 월경통이 의심되면 골반 초음파, CA-125, 필요 시 복강경. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 소염진통제, 열찜질, 경구피임약 선택지, 통증 일지 (1)
- [ ] 재방문·응급 기준 — 갑자기 심해지는 통증, 발열, 과다 출혈, 임신 가능성 (2)
