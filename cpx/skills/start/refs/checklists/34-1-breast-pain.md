# 주호소별 채점표 — 유방통

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 통증 특성 → 유방덩이·감염 동반 증상 → 위험인자 → 시진·촉진·림프절 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 통증 (10점)
- [ ] 위치 — 한쪽·양쪽, 특정 부위 (2)
- [ ] 양상·강도·지속 (2)
- [ ] 발병 시기와 경과 (2)
- [ ] 월경 주기와의 관계 (2)
- [ ] 악화·완화 요인 — 브래지어·운동 (2)

### B. 동반 증상 (10점)
- [ ] 유방에서 덩이가 만져지는지 (3)
- [ ] 유두 분비물·함몰·피부 변화 (2)
- [ ] 열·붉어짐·열감(유방염) (2)
- [ ] 최근 출산·수유 (1)
- [ ] 외상 (1)
- [ ] 겨드랑이 덩이 (1)

### C. 위험인자와 원인 (10점)
- [ ] 유방암·난소암 가족력 (3)
- [ ] 복용 약 — 호르몬제·피임약·카페인 (2)
- [ ] 월경·초경·폐경·임신·수유력 (2)
- [ ] 유방 검사(초음파·유방촬영) 이력 (2)
- [ ] 가슴벽·늑연골 통증(유방 외 원인) (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 유방 시진 — 대칭·피부·유두 함몰 (3)
- [ ] 촉진 — 방법(손 모양·압력), 모든 사분면, 압통 부위·덩이 (4)
- [ ] 겨드랑이·쇄골 림프절 촉진 (3)
- [ ] 유두 짜기(분비물) (1)
- [ ] 가슴벽 압통(늑연골) (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  덩이가 없으면 검사 없이 안심과 경과 관찰이 정답이다. 40세 이상이면 유방촬영, 젊으면 유방 초음파, 덩이가 있으면 조직검사. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 카페인 줄이기, 브래지어, 진통제, 월경 주기 일지 (1)
- [ ] 재방문·응급 기준 — 덩이가 만져짐, 피부·유두 변화, 열·발적, 통증 지속 (2)
