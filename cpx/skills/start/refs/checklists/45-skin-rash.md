# 주호소별 채점표 — 피부 발진

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 발진 특성 → 감염·자가면역·응급 알레르기 동반 증상 → 원인 노출 → 병변 기술 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 발진 (10점)
- [ ] 발생 시기·경과·부위 (3)
- [ ] 양상 — 가려움·통증·수포·비늘 (2)
- [ ] 퍼져 나간 순서와 범위 (2)
- [ ] 악화·완화 요인 — 햇빛·약·접촉 (2)
- [ ] 이전 유사 발진 (1)

### B. 동반 증상 (10점)
- [ ] 열·근육통·인후통·상기도 증상(바이러스) (2)
- [ ] 관절통·입안 궤양·탈모·햇빛 과민(루푸스) (2)
- [ ] 숨참·입술 부종·어지러움(알레르기 응급) (2)
- [ ] 눈 충혈·점막 병변·심한 통증(중증 약진) (2)
- [ ] 발열 뒤 발진(홍역·수두) (1)
- [ ] 림프절 붓기 (1)

### C. 원인 노출 (10점)
- [ ] 새 약·건강식품·백신 (3)
- [ ] 접촉 물질 — 화장품·금속·식물·세제 (2)
- [ ] 감염 접촉·예방접종·유행 질환(신고 대상 확인) (2)
- [ ] 알레르기·아토피·자가면역 병력 (2)
- [ ] 여행·동물·벌레 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 발진 기술 — 형태(반점·구진·수포)·분포·색·크기·배열 (5)
- [ ] 눌러서 색이 변하는지(자반 구별) (1)
- [ ] 점막·입안·눈 관찰 (2)
- [ ] 림프절·간·비장 촉진 (2)
- [ ] 활력징후·체온 (1)
- [ ] 관절 진찰과 다른 장기 소견 (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  감별이 필요하면 혈액검사(염증·자가항체), 피부 조직검사, 알레르기 검사, 접촉 의심에 첩포 검사. 흔한 바이러스 발진은 검사 없이 경과 관찰도 정답이다. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인 노출 피하기, 보습·소양 조절, 감염성이면 격리와 신고 안내 (1)
- [ ] 재방문·응급 기준 — 숨참·입술 부종, 점막 침범, 고열, 피부 벗겨짐·수포 확산 (2)
