# 주호소별 채점표 — 가정폭력

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 안전한 면담 환경 → 폭력 확인 → 위험도 평가 → 지원체계와 환자의 바람 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 내원 사유와 폭력 확인 (12점)
- [ ] 안전한 면담 환경 — 단둘이 면담, 비밀보장 설명 (2)
- [ ] 부상·증상이 어떻게 생겼는지 개방적으로 질문 (2)
- [ ] 폭력 여부를 비난 없이 직접 묻기 (3)
- [ ] 가해자가 누구인지, 환자와의 관계 (1)
- [ ] 폭력이 시작된 시기·빈도·가장 최근·가장 심했던 때 (2)
- [ ] 폭력 유형 — 신체·정서·성적·경제적 통제 (2)

### B. 위험도 평가 (10점)
- [ ] 목 조름·흉기·의식 소실 등 치명적 폭력 여부 (2)
- [ ] 최근 폭력이 잦아지거나 심해졌는지 (1)
- [ ] 자녀·다른 가족의 피해나 목격 (2)
- [ ] 자살·자해 생각 (2)
- [ ] 임신 여부 (1)
- [ ] 가해자의 음주·약물·총기 접근 (2)

### C. 지원체계와 대처 (8점)
- [ ] 지금 안전한 곳이 있는지, 귀가 시 위험 (2)
- [ ] 주변 지원(가족·친구), 이전에 도움을 청한 경험 (2)
- [ ] 이전 신고·상담 경험 (2)
- [ ] 환자가 원하는 것 — 떠날지, 유지할지, 무엇이 필요한지 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 진찰 전 설명·동의, 환자가 원치 않는 부분 존중 (1)
- [ ] 전신 시진 — 다양한 치유 단계의 멍·화상·물린 자국 (3)
- [ ] 손상 부위의 크기·위치·색을 기록하고 사진 촬영은 동의를 받아 진행 (3)
- [ ] 머리·목(목 졸림 흔적·점상출혈)·고막 확인 (2)
- [ ] 정신상태 평가 — 불안·우울·자살 위험 (2)
- [ ] 골절 의심 부위 압통·움직임, 임신 시 복부 확인 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 손상 사진·진단서 등 법적 증거 기록.
  있으면 더 좋음(없어도 O) — 골절·두부 손상이 의심되면 영상검사.
  진단과 어긋나면 X.
- [ ] 치료와 안전 계획 — 응급 부상 처치, 안전한 장소·연락처·비상 가방 준비 (1)
- [ ] 지원 연결과 신고 — 여성긴급전화 1366·112·쉼터 안내, 신고 의무·환자 동의, 다음 방문 약속 (2)

## 치명적 오류 (SKILL.md 의 치명적 오류 규칙)

이번 시나리오에서 아래 중 하나라도 명백히 해당하면 총점은 그대로 두고 등급을 미흡으로 한다.
- 치명: 피해자의 안전(귀가 시 위험, 안전한 장소)을 확인하지 않고 귀가 안내로 끝냄
- 치명: 아동·노인 학대 시나리오(dv-child-physical, dv-elder-neglect)에서 신고·보호 조치를 전혀 언급하지 않음
