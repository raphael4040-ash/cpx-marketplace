# 주호소별 채점표 — 수면장애

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 수면 양상 → 수면무호흡·하지불안·정신 질환 동반 증상 → 물질·약물·환경 → 정신상태 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 수면 양상 (10점)
- [ ] 잠들기 어려움·자주 깸·일찍 깸 (3)
- [ ] 발병 시기와 기간 (2)
- [ ] 하루 수면 시간과 수면 습관 (2)
- [ ] 낮 졸림·기능 저하 (2)
- [ ] 이전 경험 (1)

### B. 동반 증상과 감별 (10점)
- [ ] 코골이·숨 멈춤 목격(수면무호흡) (2)
- [ ] 다리 불편감·움직임(하지불안) (2)
- [ ] 우울·불안·걱정 (2)
- [ ] 통증·야간뇨·기침·가려움 등 신체 원인 (1)
- [ ] 갑상샘·심부전·폐 질환 (1)
- [ ] 갑작스러운 졸림·힘 빠짐(기면병) (1)
- [ ] 교대근무·시차 (1)

### C. 원인과 위험 (10점)
- [ ] 카페인·음주·니코틴·약물 (3)
- [ ] 복용 약 — 항우울제·스테로이드·각성제 (2)
- [ ] 수면 환경·화면 사용·낮잠·운동 (2)
- [ ] 스트레스·정신과 병력·자살 생각 (2)
- [ ] 수면 문제 가족력 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 정신상태 평가 (3)
- [ ] 체질량·목둘레·구인두 관찰(수면무호흡) (3)
- [ ] 갑상샘 촉진·맥박 (2)
- [ ] 심장·폐 청진·부종 (2)
- [ ] 하지 관찰·떨림 (1)
- [ ] 물질 사용 징후 (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  수면다원검사(수면무호흡 의심), 수면 일지, 갑상샘 기능·혈액검사, 우울 선별 설문. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 수면 위생, 카페인·음주 줄이기, 인지행동치료, 약 사용 주의 (1)
- [ ] 재방문·응급 기준 — 자살 생각, 낮 졸림으로 운전 위험, 숨 멈춤 심함 (2)
