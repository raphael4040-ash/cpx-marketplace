# 주호소별 채점표 — 피로

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 피로 특성 → 기질적·정신적 동반 증상 → 원인 병력 → 감별 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 피로 (10점)
- [ ] 발병 시기와 경과 (2)
- [ ] 정도와 일상 영향 (2)
- [ ] 휴식으로 좋아지는지, 하루 중 변화 (2)
- [ ] 6개월 이상 지속(만성) (1)
- [ ] 근력 약화와 구별 (1)
- [ ] 이전 경험 (2)

### B. 동반 증상 (10점)
- [ ] 체중감소·밤에 땀·림프절 붓기(기질적 원인) (3)
- [ ] 우울·흥미 저하·수면 (2)
- [ ] 추위·변비·체중 증가·피부 건조(갑상샘저하) (2)
- [ ] 빈혈 — 월경과다·검은 변·창백 (1)
- [ ] 열·관절통·근육통 (1)
- [ ] 코골이·수면 (1)

### C. 원인 (10점)
- [ ] 복용 약 — 진정제·베타차단제 (2)
- [ ] 카페인·음주·약물 (2)
- [ ] 만성 질환 — 당뇨·심부전·신장·간 (2)
- [ ] 스트레스·직장·돌봄 부담 (2)
- [ ] 최근 감염(단핵구증 등) (1)
- [ ] 가족력·임신·수유 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 활력징후·체중 (1)
- [ ] 갑상샘 촉진 (2)
- [ ] 림프절 촉진 — 경부·겨드랑이·서혜부 (3)
- [ ] 심장·폐 청진 (2)
- [ ] 복부 진찰 — 간·비장 비대 (2)
- [ ] 결막 창백·황달·피부 (1)
- [ ] 정신상태 평가 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 혈액검사(혈색소·갑상샘·혈당·간·신장 기능·염증 수치), 소변검사.
  있으면 더 좋음(없어도 O) — 흉부 X-ray·영상.
  진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인 교정, 수면·운동·식사 습관, 증상 일지 (1)
- [ ] 재방문·응급 기준 — 체중 감소·열·림프절 붓기, 흉통·숨참, 우울·자살 생각 (2)
