# 주호소별 채점표 — 물질오남용

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 사용 양상 → 의존 평가 → 건강 위험·정신 병력 → 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 물질 사용 (10점)
- [ ] 물질 종류와 형태 — 술·약·마약·수면제·니코틴 (2)
- [ ] 사용을 시작한 시기와 계기 (2)
- [ ] 빈도·양·마지막 사용 (2)
- [ ] 사용 방법 — 정맥·흡입 (2)
- [ ] 조절·중단 시도와 결과 (2)

### B. 의존 평가 (10점)
- [ ] 내성(양이 늘어남)과 금단 증상 (3)
- [ ] 사용 통제 상실·갈망 (2)
- [ ] 일·학업·가정·법적 문제 (2)
- [ ] 위험한 상황에서 사용(운전 등) (1)
- [ ] 끊으려던 시도와 실패 (1)
- [ ] 주사 공유·위험한 성 행동 (1)

### C. 건강 위험과 배경 (10점)
- [ ] 관련 건강 문제 — 간·심장·감염 (2)
- [ ] 정신과 병력과 자살 생각 (2)
- [ ] 다른 물질·음주 병용 (1)
- [ ] 우울·불안 동반 (1)
- [ ] 가족력·주변 환경 (1)
- [ ] 감염 병력 — HIV·간염 (1)
- [ ] 지지 자원과 이전 치료 경험 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 활력징후와 전신 상태 (2)
- [ ] 정신상태 평가 — 각성·기분·지각·판단 (3)
- [ ] 주사 자국·피부·치아·비강 관찰 (2)
- [ ] 동공·호흡·맥박 — 중독·금단 징후 (2)
- [ ] 간 촉진·황달·복부 (2)
- [ ] 떨림·발한(금단) (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 소변 약물검사, 간기능·혈액검사.
  있으면 더 좋음(없어도 O) — 감염 검사(HIV·간염).
  진단과 어긋나면 X.
- [ ] 치료 방향 — 동기 강화 상담, 중독 치료 기관 연계, 판단하지 않는 태도 (1)
- [ ] 재방문·응급 기준 — 금단 증상 악화, 과다 사용 뒤 의식 저하·호흡 억제, 자해 생각 (2)
