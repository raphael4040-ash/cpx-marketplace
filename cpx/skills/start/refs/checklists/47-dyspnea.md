# 주호소별 채점표 — 호흡곤란

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~D | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 E | 12 |
| I-6 Safety netting (7) | 아래 F | 7 |

면담은 급성·만성과 중증도 파악 → 호흡기·심장·대사 동반 증상 → 원인 병력과 위험 노출 → 응급 신호
순서로 좁혀 가는 것이 기준이다. 안정 시 호흡곤란이 있으면 중증도를 먼저 확인했는지 본다.
순서가 크게 흐트러지면 PPI 의 "질문 순서"에 반영한다.

## 병력청취

### A. 호흡곤란 자체 (10점)
- [ ] 발병 시기 — 갑자기인지 서서히인지, 몇 시간·며칠·몇 달 (2)
- [ ] 안정 시인지 활동 시인지, 어느 정도 활동에서 숨이 찬지 (2)
- [ ] 악화·완화 요인 — 눕거나 누울 때, 운동, 알레르겐·찬 공기, 쉬면 나아지는지 (2)
- [ ] 양상 — 쌕쌕거림, 숨이 깊이 안 들어감, 손발·입 주위 저림 (2)
- [ ] 과거 유사 발작, 빈도와 호전 경과 (2)

### B. 동반 증상 (8점)
- [ ] 기침·가래·객혈 (2)
- [ ] 가슴통증 (1)
- [ ] 열·오한 (1)
- [ ] 누우면 심해지는지·밤에 숨 차서 깨는지·다리 붓기 — 심부전 감별 (2)
- [ ] 두근거림·어지러움·실신 (1)
- [ ] 갈증·소변 증가·구역·복통 — 대사산증 감별 (1)

### C. 원인 병력 (8점)
- [ ] 천식·알레르기·만성폐쇄폐질환·심장 질환 병력 (2)
- [ ] 흡연력·직업 노출·먼지 (2)
- [ ] 당뇨병, 신장질환, 빈혈·월경과다·흑색변 등 출혈 원인 (2)
- [ ] 복용 약 — 흡입제, 혈압약(베타차단제)·소염진통제 / 최근 수술·장시간 이동·감염 (1)
- [ ] 불안·스트레스·공황 삽화 (1)

### D. 응급 신호와 가족력 (4점)
- [ ] 말하기 힘든지, 입술이 파래지는지, 안정 시에도 숨이 찬지 (2)
- [ ] 천식·알레르기·심장 질환 가족력 (2)

## 신체진찰

### E. 핵심 진찰 (12점)
- [ ] 호흡 관찰 — 호흡수·보조근 사용·청색증, 결막 창백·손톱 (2)
- [ ] 폐 청진 — 좌우 비교, 천명음·수포음·호흡음 감소 (3)
- [ ] 폐 타진과 성음 진탕 (2)
- [ ] 심장 청진 — 심잡음·심음 (2)
- [ ] 경정맥 확장·하지 부종 (1)
- [ ] 산소포화도 측정 언급, 동맥혈 채혈 준비와 설명 — Allen 검사, 소독, 채혈 부위 (2)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### F. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수(그 시나리오의 진단에 해당하는 것만) — 천식·만성폐쇄폐질환은 폐기능검사와 흉부 X-ray, 심부전은 흉부 X-ray·심전도·BNP, 케톤산증은 동맥혈가스·혈당·전해질, 빈혈은 혈색소검사.
  있으면 더 좋음(없어도 O) — 심부전 의심에 심초음파, 빈혈 의심에 출혈원 검사.
  진단과 어긋나면 X.
- [ ] 치료와 생활 교육 — 산소·흡입제 등 응급 조치, 유발 요인 피하기, 금연 (1)
- [ ] 재방문·응급 기준 — 안정 시 숨참 악화, 입술 청색, 말하기 어려움, 흉통·실신, 의식 변화 (2)

## 치명적 오류 (SKILL.md 의 치명적 오류 규칙)

이번 시나리오에서 아래 중 하나라도 명백히 해당하면 총점은 그대로 두고 등급을 미흡으로 한다.
- 치명: 응급 진단 시나리오(dys-hf, dys-dka, dys-asthma)에서 (가) 응급 처치·입원·응급 검사의 필요성을 어디에서도 말하지 않고 귀가·외래 경과 관찰·대증 처방(진통제·흡입제 등)만 함, 또는 (나) 검사를 말했더라도 추정진단이 응급 진단과 어긋나고 검사 결과 전에 귀가·대증 처방을 계획함(결과 전에는 귀가시키지 않겠다거나 입원·응급실 이송을 말했으면 해당하지 않는다)
