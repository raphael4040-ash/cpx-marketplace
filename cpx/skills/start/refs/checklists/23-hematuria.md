# 주호소별 채점표 — 붉은색 소변

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 진짜 혈뇨 확인 → 통증·감염·신장 동반 증상 → 원인 병력과 약물 → 신체진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 소변 색과 경과 (10점)
- [ ] 발병 시기·지속·반복 (2)
- [ ] 소변 전체인지 시작·끝인지 (2)
- [ ] 색과 덩어리 — 선홍색·콜라색 (2)
- [ ] 통증이 있는지(무통성인지) (2)
- [ ] 최근 음식·약 — 비트·리팜핀(가성 혈뇨) (1)
- [ ] 월경·질 출혈과 구별 (1)

### B. 동반 증상 (10점)
- [ ] 배뇨통·빈뇨 (1)
- [ ] 옆구리 통증·결석 산통 (2)
- [ ] 열·오한 (1)
- [ ] 부종·거품뇨·고혈압(사구체 질환) (2)
- [ ] 최근 인후염·피부 감염 (1)
- [ ] 체중감소·식욕 저하 (1)
- [ ] 멍·코피 등 출혈 성향 (2)

### C. 원인 (10점)
- [ ] 요로결석·신장 질환·다낭신 가족력 (2)
- [ ] 흡연·직업적 화학물질 노출(방광암) (2)
- [ ] 항응고제·소염진통제·사이클로포스파미드 (2)
- [ ] 최근 격한 운동·외상 (2)
- [ ] 요로 수술·시술·방사선 (1)
- [ ] 당뇨병·고혈압·전립샘 질환 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 활력징후 — 특히 혈압 (2)
- [ ] 부종(안검·하지), 피부(자반) (2)
- [ ] 복부·늑골척추각 타진·촉진 (3)
- [ ] 하복부·방광 촉진 (1)
- [ ] 외부 생식기, 남성은 전립샘 직장 진찰 (2)
- [ ] 출혈 성향 — 멍·점상출혈·결막 (2)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 소변검사·현미경(적혈구 모양), 혈액검사(크레아티닌·응고).
  있으면 더 좋음(없어도 O) — 소변 세포진, 복부 초음파·CT, 방광경.
  진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인에 따라, 무통성 혈뇨는 반드시 추적 (1)
- [ ] 재방문·응급 기준 — 덩어리 혈뇨로 소변이 막힘, 심한 옆구리 통증, 열, 어지러움 (2)
