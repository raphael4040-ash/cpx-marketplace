# 주호소별 채점표 — 의식장애

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 발견 경위(보호자·목격자) → 응급 원인(저혈당·뇌·독성) → 배경과 약물 → 의식 평가와 신경진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

보호자·목격자 역할이 응대하는 케이스이므로 병력은 보호자에게 묻는 것을 인정한다.

## 병력청취

### A. 발견 경위 (10점)
- [ ] 발견 시각과 상황 (2)
- [ ] 의식 변화 양상 — 갑자기인지 서서히인지 (2)
- [ ] 이전 증상 — 두통·구토·마비·경련 (2)
- [ ] 외상·낙상 여부 (2)
- [ ] 마지막으로 정상이었던 시각 (2)

### B. 원인 병력 (10점)
- [ ] 당뇨병과 인슐린·혈당 약 (2)
- [ ] 간·신장 질환·음주 (2)
- [ ] 뇌졸중·심장·고혈압 병력 (2)
- [ ] 약물·독극물·약 과다 복용(수면제 등) (2)
- [ ] 열·감염 증상 (1)
- [ ] 자살 생각·정신과 병력 (1)

### C. 배경 (10점)
- [ ] 복용 약과 알레르기 (2)
- [ ] 음주·약물 사용 (2)
- [ ] 과거 유사 발작·경련 (2)
- [ ] 최근 스트레스·사건 (1)
- [ ] 보호자 정보와 의무기록 (3)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 의식 수준 평가(GCS) (3)
- [ ] 기도·호흡·순환과 활력징후 (2)
- [ ] 안저검사 (2)
- [ ] 동공 반사·안구 운동 (2)
- [ ] 목 강직 (1)
- [ ] 운동 반응·병적 반사 (2)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 즉시 혈당, 혈액·전해질·간·신장 기능, 뇌 CT.
  있으면 더 좋음(없어도 O) — 동맥혈가스, 약물 검사, MRI.
  진단과 어긋나면 X.
- [ ] 응급 처치와 보호자 설명 — 기도 유지, 저혈당 교정, 원인 치료 (1)
- [ ] 경과 관찰·재평가 기준 — 의식 저하 악화, 경련, 호흡 이상, 새 신경학적 이상 (2)

## 치명적 오류 (SKILL.md 의 치명적 오류 규칙)

이번 시나리오에서 아래 중 하나라도 명백히 해당하면 총점은 그대로 두고 등급을 미흡으로 한다.
- 치명: 응급 진단 시나리오(alt-hypoglycemia, alt-ich, alt-csdh, alt-hepatic, alt-sedative(모든 시나리오))에서 (가) 응급 처치·입원·응급 검사의 필요성을 어디에서도 말하지 않고 귀가·외래 경과 관찰·대증 처방(진통제·흡입제 등)만 함, 또는 (나) 검사를 말했더라도 추정진단이 응급 진단과 어긋나고 검사 결과 전에 귀가·대증 처방을 계획함(결과 전에는 귀가시키지 않겠다거나 입원·응급실 이송을 말했으면 해당하지 않는다)
