# 주호소별 채점표 — 콧물/코막힘

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 콧물·코막힘 특성 → 알레르기·부비동염·편측 위험 동반 증상 → 환경·약물 → 비강·이경 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 증상 (10점)
- [ ] 콧물 성상 — 맑은지 화농성인지 (2)
- [ ] 코막힘 — 한쪽·양쪽·교대 (2)
- [ ] 발병 시기·기간·계절 (2)
- [ ] 악화·완화 요인 — 먼지·꽃가루·찬 공기·약 (2)
- [ ] 이전 유사·반복 (2)

### B. 동반 증상 (10점)
- [ ] 재채기·코·눈 가려움(알레르기) (2)
- [ ] 안면통·두통·후각 저하(부비동염) (2)
- [ ] 열·인후통·기침(감염) (1)
- [ ] 코피·한쪽 혈성 분비물 (2)
- [ ] 귀 먹먹·귀 통증·청력 (1)
- [ ] 코골이·수면 (1)
- [ ] 천식 증상 (1)

### C. 원인 (10점)
- [ ] 알레르기·아토피·천식 병력과 가족력 (3)
- [ ] 복용 약·비강 스프레이 남용·혈압약 (2)
- [ ] 환경 — 먼지·동물·직장·흡연 (2)
- [ ] 코 외상·수술 (2)
- [ ] 이전 비염·부비동염 치료 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 비강 검사 — 비경 사용, 점막 색·부종·분비물·비중격·용종·이물 (5)
- [ ] 부비동 압통(전두·상악) (2)
- [ ] 이경검사 — 이개 당김, 고막 관찰 (3)
- [ ] 인두·편도·후비루 (1)
- [ ] 경부 림프절·폐 청진 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  일반 비염·감기는 검사 없이 경과 관찰도 정답이다. 알레르기 의심에 피부반응검사·혈청 IgE, 부비동염 의심에 부비동 X-ray·CT, 편측 지속에 비내시경·조직검사. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인 물질 피하기, 식염수 세척, 항히스타민·비강 스프레이 올바른 사용 (1)
- [ ] 재방문·응급 기준 — 한쪽 코막힘 지속·코피, 고열, 안면 부기·시력 변화, 2~3주 이상 지속 (2)
