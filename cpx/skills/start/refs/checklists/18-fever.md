# 주호소별 채점표 — 발열

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~D | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 E | 12 |
| I-6 Safety netting (7) | 아래 F | 7 |

면담은 열 자체 → 장기별 감염 증상 훑기 → 노출·면역 상태·시술력 → 중증도 순서로 좁혀 가는
것이 기준이다. 감염 원인을 찾을 때 계통별 문진(호흡기·비뇨기·소화기·신경)을 빠뜨리지 않았는지
본다. 순서가 크게 흐트러지면 PPI 의 "질문 순서"에 반영한다.

## 병력청취

### A. 열 자체 (10점)
- [ ] 발병 시기와 경과 — 언제부터, 점점 오르는지 (2)
- [ ] 체온을 재었는지, 최고 체온 (2)
- [ ] 열 양상 — 지속인지 오르내리는지, 오한·떨림, 밤에 땀 (2)
- [ ] 해열제 복용과 반응 (1)
- [ ] 이전 유사 열, 지속 기간 — 3주 이상이면 불명열 감별 (1)
- [ ] 악화·호전 경과 (2)

### B. 계통별 동반 증상 (10점)
- [ ] 기침·가래·숨참·가슴통증 — 호흡기 (2)
- [ ] 배뇨통·빈뇨·옆구리 통증 — 비뇨기 (2)
- [ ] 복통·설사·구토 — 소화기 (1)
- [ ] 두통·목 뻣뻣함·의식 변화 — 신경계 (1)
- [ ] 인후통·콧물·근육통 — 상기도·인플루엔자 (1)
- [ ] 피부 발적·상처·관절 통증 (1)
- [ ] 체중감소·식욕 저하·야간 발한 — 결핵·종양 감별 (1)
- [ ] 새로 생긴 피부 반점·발진 (1)

### C. 노출·위험요인 (8점)
- [ ] 감염자 접촉, 가족·주변 유행 (2)
- [ ] 여행·동물·곤충·날음식 노출 (1)
- [ ] 면역저하 — 당뇨병, 스테로이드, 항암치료, 장기 이식 (2)
- [ ] 최근 시술·치과 치료·정맥주사·심장판막 질환 — 심내막염 감별 (2)
- [ ] 최근 새로 시작한 약·예방접종 (1)

### D. 중증도 (2점)
- [ ] 소변량·탈수, 의식 저하·어지러움 등 패혈증 신호 (2)

## 신체진찰

### E. 핵심 진찰 (12점)
- [ ] 전신 상태 — 탈수, 의식, 활력징후 재확인 (1)
- [ ] 인두·편도·귀 관찰 (1)
- [ ] 폐 청진 (2)
- [ ] 심장 청진 — 새 심잡음 확인 (1)
- [ ] 복부 진찰과 늑골척추각 타진 (2)
- [ ] 림프절 촉진, 피부 관찰(발진·점상출혈·손톱 밑 출혈), 목 강직 (2)
- [ ] 혈액배양 채혈 — 설명, 소독, 서로 다른 두 부위에서 채혈 (3)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### F. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  폐렴 의심에 흉부 X-ray·객담검사, 신우신염 의심에 소변검사·소변배양,
  심내막염 의심에 혈액배양 반복·심초음파, 인플루엔자 의심에 신속항원검사, 공통으로 혈액검사(CRP).
  진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인에 맞는 항생제·해열제, 수분 섭취, 격리 (1)
- [ ] 재방문·응급 기준 — 39도 이상 지속, 의식 저하, 숨참, 목 뻣뻣함, 소변 감소 (2)
