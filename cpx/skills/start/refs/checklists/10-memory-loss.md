# 주호소별 채점표 — 기억력 저하

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 기억 저하 양상과 진행 → 섬망·동반 증상 감별 → 원인 병력 → 인지기능검사 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

보호자가 동반한 케이스에서는 보호자에게 변화 양상을 묻는 것도 병력 항목으로 인정한다.

## 병력청취

### A. 기억력 저하 자체 (10점)
- [ ] 발병 시기와 진행 속도 — 서서히인지 갑자기인지 (3)
- [ ] 어떤 기억인지 — 최근 일·오래된 일 (2)
- [ ] 구체적 사례 — 약속·물건·길 잃음 (2)
- [ ] 일상생활·금전 관리·운전에 미치는 영향 (2)
- [ ] 이전 진단·검사 (1)

### B. 동반 증상과 감별 (10점)
- [ ] 갑작스러운 혼돈·주의 변동·환각(섬망) (3)
- [ ] 성격·행동 변화, 우울·무감동 (2)
- [ ] 언어 문제·길 찾기·판단력 저하 (2)
- [ ] 보행 이상·떨림·요실금 (2)
- [ ] 두통·머리 외상 (1)

### C. 원인 병력 (10점)
- [ ] 고혈압·당뇨병·뇌졸중·심방세동 (2)
- [ ] 음주력 (2)
- [ ] 복용 약 — 항콜린제·수면제 (2)
- [ ] 우울·수면·청력·시력 문제 (1)
- [ ] 머리 수술·감염 병력 (1)
- [ ] 치매 가족력 (1)
- [ ] 교육 수준·사회 활동 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 기본 인지기능검사 — 지남력·기억(3단어)·주의력·언어·시공간(시계 그리기) (6)
- [ ] 뇌신경·운동·감각 (2)
- [ ] 보행과 파킨슨 징후 — 경직·서동·떨림 (2)
- [ ] 반사·병적 반사 (1)
- [ ] 갑상샘·활력징후·혈압 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  뇌 MRI·CT, 갑상샘 기능·비타민 B12·혈당·전해질 등 혈액검사, 신경심리검사. 진단과 어긋나면 X.
- [ ] 보호자 교육 — 안전(가스·길 잃음)·일정 관리·돌봄 자원 안내 (1)
- [ ] 재방문·응급 기준 — 갑자기 심해지는 혼돈, 길 잃음, 새 마비·보행 장애 (2)
