# 주호소별 채점표 — 목통증/허리통증

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 통증 특성 → 적신호 → 원인·연관통 → 신경학적 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 통증 자체 (10점)
- [ ] 발병 시기와 계기 — 외상·무거운 것 들기 (2)
- [ ] 위치와 방사 — 다리로 뻗치는지 (2)
- [ ] 양상과 강도 (2)
- [ ] 악화·완화 요인 — 자세·기침·앉기·걷기·휴식 (2)
- [ ] 야간통·안정 시 통증 (2)

### B. 적신호 (10점)
- [ ] 대소변 장애·안장 감각 저하·양측 다리 힘 빠짐 (3)
- [ ] 열·오한 (1)
- [ ] 체중감소·암 병력 (2)
- [ ] 휴식해도 지속되는 통증 (1)
- [ ] 외상·골다공증·스테로이드 사용 (1)
- [ ] 정맥주사 남용·최근 감염·시술 (1)
- [ ] 다리 위약·감각 저하 (1)

### C. 원인과 연관통 (10점)
- [ ] 직업·자세·운동 (2)
- [ ] 과거 요통·수술 (2)
- [ ] 강직척추염 — 아침 강직 30분 이상, 젊은 나이, 엉덩이 통증 (2)
- [ ] 연관통 — 배·옆구리·혈뇨 등 장기 증상 (2)
- [ ] 복용 약과 진통제 반응 (1)
- [ ] 일상·직장에 미치는 영향 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 척추 시진(정렬)·촉진(압통·극돌기) (2)
- [ ] 운동범위 (2)
- [ ] 하지 직거상 검사·신경뿌리 자극 검사 (2)
- [ ] 근력·감각·심부건반사 (3)
- [ ] 천장관절·고관절 검사 (1)
- [ ] 연관통 확인 — 늑골척추각 타진·복부·말초 맥박 (1)
- [ ] 안장 감각·항문 긴장도(필요 시) (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  적신호 없으면 영상 없이 경과 관찰도 정답이다. 적신호가 있으면 척추 MRI·X-ray, 혈액검사(ESR·CRP), 연관통 의심 시 복부 초음파·소변검사. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 활동 유지, 자세, 진통제, 운동 (1)
- [ ] 재방문·응급 기준 — 대소변 장애, 다리 힘 빠짐, 안장 감각 저하, 열, 야간 통증 악화 (2)
