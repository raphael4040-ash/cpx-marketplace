# 주호소별 채점표 — 유방덩이

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 덩이 특성 → 악성 시사 소견 → 위험인자 → 유방 진찰과 전이 확인 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 덩이 (10점)
- [ ] 발견 시기와 계기 (2)
- [ ] 위치·크기 변화 (2)
- [ ] 통증 유무 (1)
- [ ] 월경 주기에 따른 변화 (2)
- [ ] 이전 덩이·조직검사 (2)
- [ ] 이전 검사(초음파·유방촬영) (1)

### B. 동반 증상 (10점)
- [ ] 유두 분비물(혈성)·함몰 (2)
- [ ] 피부 변화 — 귤껍질·함몰 (2)
- [ ] 겨드랑이 덩이 (1)
- [ ] 체중감소·뼈 통증·기침·황달(전이) (2)
- [ ] 열·붉어짐(감염) (1)
- [ ] 외상 (1)
- [ ] 임신·수유 (1)

### C. 위험인자 (10점)
- [ ] 유방암·난소암 가족력, BRCA (3)
- [ ] 초경·폐경·초산 나이·수유 (2)
- [ ] 호르몬 치료·피임약 (1)
- [ ] 음주·비만·방사선 노출 (2)
- [ ] 이전 유방 질환 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 유방 시진 (2)
- [ ] 촉진 — 덩이의 위치·크기·경도·표면·경계·유동성·피부·근막 고정 (5)
- [ ] 반대쪽 유방과 비교 (1)
- [ ] 겨드랑이·쇄골 림프절 촉진 (2)
- [ ] 전이 확인 — 간 촉진·척추 압통·폐 청진 (2)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 유방 초음파·유방촬영, 덩이 조직검사(침생검).
  있으면 더 좋음(없어도 O) — MRI, 전이 검사.
  진단과 어긋나면 X.
- [ ] 치료와 교육 — 양성·악성 가능성을 솔직하고 차분하게 설명, 조직검사 필요성 (1)
- [ ] 재방문 기준 — 검사 결과 확인 일정, 덩이 커짐, 피부 변화 (2)
