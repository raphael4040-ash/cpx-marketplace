# 주호소별 채점표 — 관절통증/부기

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 관절 침범 양상 → 염증·감염 동반 증상 → 원인과 위험요인 → 일상 영향 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 관절통 자체 (10점)
- [ ] 위치 — 어느 관절인지, 한 곳인지 여러 곳인지, 좌우 대칭인지 (2)
- [ ] 발병 양상(갑자기·서서히)과 시기 (2)
- [ ] 아침 강직이 30분 이상인지 (2)
- [ ] 악화·완화 요인 — 움직임·휴식 (2)
- [ ] 붓기·열감·발적 (1)
- [ ] 이전에도 같은 증상이 있었는지, 반복되는지 (1)

### B. 동반 증상 (8점)
- [ ] 열·오한(감염관절염) (2)
- [ ] 피부 발진·건선·햇빛 과민 (1)
- [ ] 입·눈 건조, 입안 궤양 (1)
- [ ] 설사·요도염·눈 충혈(반응성 관절염) (1)
- [ ] 체중감소·피로 (1)
- [ ] 허리 통증·척추 강직 (1)
- [ ] 다른 관절·근육 통증(섬유근육통) (1)

### C. 원인과 위험요인 (12점)
- [ ] 외상·과사용·직업 활동 (2)
- [ ] 통풍 위험 — 음주·고기·이뇨제·요산 병력 (2)
- [ ] 감염 위험 — 최근 관절 시술·주사·성 접촉·피부 상처 (2)
- [ ] 류마티스·자가면역·건선 가족력 (2)
- [ ] 복용 약 — 스테로이드·진통제·이뇨제 (2)
- [ ] 일상·직업에 미치는 영향 (2)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 관절 시진·촉진 — 발적·열감·부종·압통·삼출 (3)
- [ ] 관절 운동범위(능동·수동)와 통증 유발 (3)
- [ ] 인접 관절·다른 관절 침범 확인 (2)
- [ ] 체온 등 활력징후 (1)
- [ ] 신경·근력 확인 (1)
- [ ] 관절 외 소견 — 피부·손톱·눈·심장 (2)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수(그 시나리오의 진단에 해당하는 것만) — 급성 단일관절 염증은 관절천자와 액 분석·배양, 통풍은 요산·편광현미경, 류마티스는 RF·anti-CCP·CRP·ESR, 골관절염·반월상연골 손상은 관절 X-ray.
  있으면 더 좋음(없어도 O) — 혈액배양.
  진단과 어긋나면 X.
- [ ] 치료와 교육 — 휴식·냉찜질·약 사용, 감염이 의심되면 응급 처치 필요성 (1)
- [ ] 재방문·응급 기준 — 급성 발적·열감, 열, 움직이지 못함, 여러 관절로 번짐 (2)
