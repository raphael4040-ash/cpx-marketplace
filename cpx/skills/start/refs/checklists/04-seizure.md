# 주호소별 채점표 — 경련

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 경련 상황(목격자 진술 포함) → 실신 등 경련 유사 증상 구별 → 원인·위험인자 → 생활 영향 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 경련 상황 (12점)
- [ ] 발생 시각과 지속 시간 (2)
- [ ] 전조 — 냄새·기시감·어지러움 (2)
- [ ] 경련 양상 — 전신·국소, 눈 돌아감, 강직·떨림(목격자 진술) (3)
- [ ] 의식 소실·회복 양상 — 멍한 시간, 혀 깨묾, 소변 실금 (3)
- [ ] 발생 전 상황 — 수면 부족·음주·스트레스·발열 (2)

### B. 감별과 위험인자 (10점)
- [ ] 실신 구별 — 서 있다가 쓰러졌는지, 식은땀, 빠른 회복 (2)
- [ ] 두통·열·목 뻣뻣함(뇌염·수막염) (2)
- [ ] 머리 외상·뇌졸중·뇌종양 병력 (2)
- [ ] 이전 경련, 소아기 열성경련 (1)
- [ ] 음주·약물 금단, 저혈당(당뇨 약) (2)
- [ ] 복용 약, 최근 항경련제를 끊었는지 (1)

### C. 기타 (8점)
- [ ] 뇌전증 가족력 (1)
- [ ] 출생 시 문제·발달 이상 (1)
- [ ] 임신 가능성·월경 (1)
- [ ] 운전·직업·일상에 미치는 영향 (2)
- [ ] 목격자 진술을 확보했는지 (2)
- [ ] 경련 뒤 마비·언어 이상 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 의식·지남력·언어 (2)
- [ ] 뇌신경 검사 (2)
- [ ] 운동·감각·심부건반사 (3)
- [ ] 혀·구강 외상, 머리 외상 확인 (1)
- [ ] 목 강직 (2)
- [ ] 체온·혈당 확인 언급 (1)
- [ ] 병적 반사(Babinski) (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  뇌파, 뇌 MRI·CT, 혈당·전해질·혈액검사, 감염 의심 시 요추천자. 진단과 어긋나면 X.
- [ ] 교육 — 규칙적 수면, 음주 피하기, 운전·수영·고소 작업 금지, 발작 시 옆으로 눕히기 (1)
- [ ] 응급 기준 — 5분 이상 지속, 연속 경련, 의식 회복 없음, 새 마비·두통·열 (2)
