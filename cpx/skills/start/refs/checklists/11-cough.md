# 주호소별 채점표 — 기침

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~D | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 E | 12 |
| I-6 Safety netting (7) | 아래 F | 7 |

면담은 기침 특성(급성·만성 구분) → 폐·상기도·위식도·심장 동반 증상 → 위험 노출과 복용 약 →
위험 신호(객혈·체중감소) 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 기침 자체 (10점)
- [ ] 발병 시기와 기간 — 8주를 기준으로 급성인지 만성인지 (2)
- [ ] 양상 — 마른기침인지 가래가 있는지, 밤·새벽에 심한지, 발작적인지 (2)
- [ ] 가래의 색·양·냄새, 피가 섞였는지 (2)
- [ ] 악화·완화 요인 — 누울 때, 식후, 찬 공기, 운동, 특정 장소·계절 (2)
- [ ] 이전에도 같은 기침이 있었는지, 반복 여부 (2)

### B. 동반 증상 (8점)
- [ ] 열·오한·밤에 땀 (2)
- [ ] 체중감소·식욕 저하 (1)
- [ ] 호흡곤란·쌕쌕거림 (2)
- [ ] 콧물·코막힘·목 뒤로 넘어가는 느낌 (1)
- [ ] 속쓰림·신물 넘어옴 (1)
- [ ] 가슴통증 (1)

### C. 원인 병력 (8점)
- [ ] 흡연력(갑년)·직업·먼지 노출 (2)
- [ ] 결핵 환자 접촉·결핵 병력 (2)
- [ ] 복용 약 — 특히 혈압약(ACE 억제제) (2)
- [ ] 천식·알레르기·만성폐쇄폐질환·심장질환 병력 (1)
- [ ] 최근 감기·주변 유행 (1)

### D. 위험 신호와 기타 (4점)
- [ ] 객혈의 양, 기침 뒤 어지러움·실신 (2)
- [ ] 면역저하 — 스테로이드·HIV·항암치료 (1)
- [ ] 가족 병력 (1) — 공통 I-5 의 가족력 칸을 대신한다.

## 신체진찰

### E. 핵심 진찰 (12점)
- [ ] 전신 관찰 — 야윔·청색증·곤봉지, 호흡수 (2)
- [ ] 폐 청진 — 좌우 비교, 수포음·천명음·호흡음 감소 (3)
- [ ] 폐 타진과 성음 진탕 (2)
- [ ] 심장 청진 (2)
- [ ] 코·목 안 관찰(후인두 점액), 경부 림프절 촉진 (2)
- [ ] 동맥혈 채혈 — 설명, Allen 검사, 소독, 채혈 부위 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### F. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수(그 시나리오의 진단에 해당하는 것만) — 만성기침·결핵 의심은 흉부 X-ray와 객담 항산균 검사, 만성폐쇄폐질환은 폐기능검사와 흉부 X-ray, ACE 억제제 기침은 약 변경 후 경과 관찰.
  진단과 어긋나면 X.
- [ ] 치료와 생활 교육 — 금연, 원인 약 조정, 수분 섭취, 결핵 의심 시 마스크·격리 (1)
- [ ] 재방문 기준 — 피 섞인 가래, 숨참 악화, 고열 지속, 체중감소, 8주 이상 지속 (2)
