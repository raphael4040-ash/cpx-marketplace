# 주호소별 채점표 — 기분 변화

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 기분 증상 → 동반·감별(조증·물질·신체질환) → 자살 위험 평가 → 정신상태 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 기분 자체 (10점)
- [ ] 우울감·흥미 상실 — 핵심 증상 (3)
- [ ] 지속 기간(2주 이상인지) (2)
- [ ] 일상 기능 저하 — 직장·학업·관계 (2)
- [ ] 발병 계기 — 상실·스트레스 (2)
- [ ] 이전 삽화 (1)

### B. 동반 증상과 감별 (10점)
- [ ] 수면·식욕·체중 변화 (2)
- [ ] 피로·집중력 저하·죄책감 (2)
- [ ] 조증 삽화 — 들뜸·수면 필요 감소·과소비 (2)
- [ ] 불안·공황·망상·환청 (2)
- [ ] 음주·약물 사용 (1)
- [ ] 신체질환(갑상샘 등)·복용 약 (1)

### C. 자살 위험 평가 (10점)
- [ ] 자살 생각을 직접 묻기 — 필수 (4)
- [ ] 자살 계획·수단·이전 시도 (3)
- [ ] 보호 요인 — 가족·자녀·종교 (1)
- [ ] 가족의 정신질환·자살력 (1)
- [ ] 자해 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 정신상태 평가 — 외모·행동·기분·정동 (3)
- [ ] 사고 과정과 내용(망상·자살 사고) (3)
- [ ] 지각(환청) (1)
- [ ] 인지·지남력·판단력·병식 (2)
- [ ] 신체 진찰 — 활력징후·체중, 갑상샘, 자해 흔적 (3)

자살 생각을 직접 묻지 않았다면 이 채점표의 자살 위험 평가 항목은 X 이고 개선점에 반드시 적는다.

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  필수 — 갑상샘 기능검사·혈액검사(신체질환 감별).
  있으면 더 좋음(없어도 O) — 우울 선별 설문.
  진단과 어긋나면 X.
- [ ] 치료 방향 — 상담·약물치료, 자살 위험이 높으면 입원·보호자 연계 (1)
- [ ] 재방문·응급 기준 — 자살 생각 악화, 위기 상담전화 1393·응급실 안내, 지지자 연결 (2)

## 치명적 오류 (SKILL.md 의 치명적 오류 규칙)

이번 시나리오에서 아래 중 하나라도 명백히 해당하면 총점은 그대로 두고 등급을 미흡으로 한다.
- 치명: 자살 생각을 직접 묻지 않음(돌려서 묻거나 판단하는 어투로 묻는 것은 직접 묻기가 아니다)
- 치명: 자살 생각이 확인됐는데 계획·수단을 묻지 않거나 안전 확보 안내 없이 면담을 끝냄
