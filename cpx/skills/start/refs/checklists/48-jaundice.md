# 주호소별 채점표 — 황달

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~C | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 D | 12 |
| I-6 Safety netting (7) | 아래 E | 7 |

면담은 황달 특성(가성 구별) → 담관·간·용혈 동반 증상 → 원인 병력 → 황달 확인과 간질환 징후 진찰 순서로 좁혀 가는 것이 기준이다. 순서가 크게 흐트러지면 PPI 의
"질문 순서"에 반영한다.

## 병력청취

### A. 황달 (10점)
- [ ] 발병 시기와 진행 (2)
- [ ] 어디가 노란지 — 눈 흰자위 색(가성 황달 구별) (2)
- [ ] 소변 색(짙음)·대변 색(회백색) (3)
- [ ] 가려움 (1)
- [ ] 이전 황달 (1)
- [ ] 경과 (1)

### B. 동반 증상 (10점)
- [ ] 복통(우상복부·상복부)·열·오한(담관염) (3)
- [ ] 구역·구토·식욕 저하·체중감소 (2)
- [ ] 피로·근육통(간염) (1)
- [ ] 등 통증·배가 그득함(췌장암) (1)
- [ ] 혼돈·졸림(간성뇌증)·출혈 (1)
- [ ] 빈혈·어지러움(용혈) (1)
- [ ] 부종·복수 (1)

### C. 원인 (10점)
- [ ] 간염·간 질환 병력, 백신, 수혈 (2)
- [ ] 음주력 (2)
- [ ] 복용 약·한약·건강기능식품(아세트아미노펜 포함) (2)
- [ ] 담석·담낭 수술 병력 (1)
- [ ] 여행·날음식·주삿바늘·성 접촉(감염) (2)
- [ ] 간질환·용혈·체질성 황달 가족력 (1)

## 신체진찰

### D. 핵심 진찰 (12점)
- [ ] 황달 관찰 — 공막·피부, 자연광에서 (2)
- [ ] 활력징후·의식(혼돈)·체온 (1)
- [ ] 복부 진찰 — 시진 → 청진 → 타진 → 촉진 순서 (4)
- [ ] 간·비장 촉진, 간 크기 타진, Murphy 징후 (2)
- [ ] 간질환 징후 — 거미혈관·손바닥 홍반·복수·부종·손 떨림 (2)
- [ ] 림프절(Virchow)·결막 창백 (1)

## 추정진단·검사·교육

### E. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  혈액검사(빌리루빈 직접·간접, 간효소, 알칼리인산분해효소, 간염 표지자, 용혈 검사), 복부 초음파·CT, 필요 시 ERCP·MRCP. 진단과 어긋나면 X.
- [ ] 치료와 교육 — 원인 치료, 음주·약 주의, 담관염 의심 시 즉시 입원 (1)
- [ ] 재방문·응급 기준 — 열·오한·복통(담관염), 의식 변화·출혈, 황달 악화 (2)
