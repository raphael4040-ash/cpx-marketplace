# 주호소별 채점표 — 혈변

`checklist.md` 의 공통 배점표 중 아래 세 칸을 이 표로 바꿔 채점한다. 나머지 칸(도입, ICE,
과거력·약물력·가족력·사회력, 진찰 전 설명과 활력징후, PPI)은 공통 배점표 그대로다.
총점 구조(병력 60 / 진찰 20 / PPI 20)는 바뀌지 않는다.
공통 배점표의 I-2 "주호소 명확화"·"과거 유사 증상", I-4 "전신 증상", I-6 "악화 시 대처"·"추가 검사 안내"는
아래 항목이 대신하며 따로 채점하지 않는다. 대응 항목이 없는 것은 의도적으로 뺀 것이다.

| 공통 배점표의 칸 | 바꿔 쓰는 칸 | 배점 |
|---|---|---|
| I-2 주호소 & 현병력 (20) + I-4 Red flag (10) | 아래 A~D | 30 |
| II 핵심 진찰 수기 1·2 (12) | 아래 E | 12 |
| I-6 Safety netting (7) | 아래 F | 7 |

면담은 출혈 자체 → 출혈량에 따른 응급 여부 → 원인 병력과 약물 → 상부·하부 구분 순서로 좁혀
가는 것이 기준이다. 출혈로 불안정해 보이는 신호(어지러움·식은땀)를 일찍 확인했는지 본다.
순서가 크게 흐트러지면 PPI 의 "질문 순서"에 반영한다.

## 병력청취

### A. 혈변 자체 (10점)
- [ ] 발병 시기와 횟수 (2)
- [ ] 출혈의 양과 색 — 선홍색인지, 암적색인지, 검붉은 변인지 (2)
- [ ] 피의 위치 — 변 표면, 휴지에만 묻는지, 변과 섞였는지, 변기에 가득 차는지 (2)
- [ ] 배변 습관·변 굵기 변화 (1)
- [ ] 배변 시 항문 통증 (1)
- [ ] 이전에도 같은 경험이 있었는지 (2)

### B. 동반 증상 (8점)
- [ ] 복통 (1)
- [ ] 어지러움·식은땀·두근거림·일어설 때 눈앞이 캄캄 — 출혈로 인한 불안정 신호 (2)
- [ ] 구역·구토·속쓰림 (1)
- [ ] 열·체중감소·식욕 저하 (2)
- [ ] 설사·잔변감 (1)
- [ ] 관절통·눈·피부·입안 궤양 (1)

### C. 원인 병력 (8점)
- [ ] 치핵·변비·용종·대장내시경 검사 이력 (2)
- [ ] 복용 약 — 항응고제·항혈소판제·소염진통제 (2)
- [ ] 음주·간질환·위궤양 병력 (2)
- [ ] 대장암·염증성 장질환 가족력 (1)
- [ ] 복부 수술·방사선 치료 (1)

### D. 상부 출혈 구별과 출혈 성향 (4점)
- [ ] 검은 변(흑색변)·토혈 여부 (2)
- [ ] 멍·코피·잇몸 출혈 등 출혈 성향 (2)

## 신체진찰

### E. 핵심 진찰 (12점)
- [ ] 혈압·맥박 측정, 기립 시 변화 — 출혈량 평가 (3)
- [ ] 복부 진찰 — 시진 → 청진 → 타진 → 촉진 순서 (3). 순서가 틀리면 △
- [ ] 항문 직장 진찰 — 설명·동의, 옆으로 누운 자세, 시진, 윤활제 사용 촉진, 장갑에 묻은 변 색 확인 (4)
- [ ] 결막 창백, 피부 점상출혈·멍 관찰 (1)
- [ ] 정맥로 확보 필요성·혈액형·교차시험 언급 (1)

## 추정진단·검사·교육 (I-6 대체, 병력청취 소계에 합산)

### F. 마무리 (7점)
- [ ] 추정진단 설명 — 가능한 원인을 환자 소견과 비교해 쉬운 말로 (2)
- [ ] 검사 계획 설명 (2) — 의심 진단에 맞아야 인정한다.
  혈색소·응고검사·혈액형, 하부 의심에 대장내시경, 상부 의심에 위내시경,
  출혈량이 많으면 수액·수혈 준비. 대량 출혈이 의심되는데 외래 추적만 계획하면 X.
- [ ] 치료와 교육 — 안정·금식, 수액, 복용 약 조정, 변비 예방 (1)
- [ ] 재방문·응급 기준 — 출혈 증가, 어지러움·실신, 검은 변, 복통 심화 (2)
